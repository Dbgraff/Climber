# Climger_pixi_rep

Однокнопочная аркадная веб-игра. Помогите альпинисту взобраться как можно выше, уклоняясь от падающих камней и не попадая в лаву.

Проект находится в стадии активной разработки как учебный.
Текущая версия распространяется под MIT для свободного
использования и изучения.

Финальная версия игры, предназначенная для публикации
на платформах (Яндекс Игры и других), будет выпущена
под отдельной лицензией.

Планы по развитию
-Главное меню и экран завершения игры
-Таблица рекордов
-Монетки и бонусы
-Интеграция с Яндекс Игры (SDK, реклама, лидерборды)
-Визуальные эффекты и анимации
-Звуковое сопровождение
